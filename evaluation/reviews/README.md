# Agent reviews

Design reviews in this folder are written by a reviewer agent that did not build the course, in a fresh context. They are labeled "Agent review" and are not reviews by real teachers, geologists or learners. The reviewer may run on the same underlying model as the builder; that is a limitation.

Planned reports: heuristics, cognitive walkthrough, multimedia principles, realism and cinematics, accessibility, expert-style (high-school earth science teacher; planetary geologist), visual quality per preset.
