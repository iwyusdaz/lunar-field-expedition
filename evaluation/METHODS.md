# Evaluation methods — lunar-field-expedition

What was checked, how, and what it can and can't show. No real learners have used this course. Nothing here is evidence of learning gains.

## Fact check
Every Apollo 15 and geology fact is in `research/apollo15-facts.md` with its source URL, access date and status: VERIFIED (source opened), VERIFIED-SNIPPET (number seen quoting a source that couldn't be opened; used only for approximate positions, flagged in the app) or DERIVED (labeled approximate). Nothing marked UNVERIFIED is used in content.

The functional and accessibility suites use a test-hooks build (`VITE_TEST_HOOKS=1`), as in CI; the sub-path test uses the release build.

**Can show:** the course works end to end in 3D and text mode; terrain relief matches published values; facts trace to sources; the overlay passes automated WCAG checks.

**Can't show:** whether students argue from evidence better, whether it fits real classrooms, or how screen-reader users experience it.

Against the budgets (standards 4.5): ≥ 55 fps on Medium (pass), ≤ 300 draw calls (pass), ≤ 1.5 M triangles (pass, Ultra included), menu interactive in 0.21 s (< 3 s, pass; measured in the page from navigation start until the Menu button is visible and no long task is running, on a local server), 5.63 MB before first interaction (≤ 15 MB desktop and ≤ 8 MB mobile, pass). Frame rate is capped by the 60 Hz display. Mobile performance is inferred from the Low preset; no phone or emulation run.

## Revision log
1. The Earth texture's CC BY 4.0 license couldn't be verified (the license page served a CAPTCHA). It was replaced with NASA's public-domain Blue Marble.
2. The poster alt text described features not in the image (a winding rille, a crater rim, a small blue Earth). Rewritten to match what the poster shows.
3. `attribution.json` wasn't regenerated by `npm run build`, so the build shipped stale credits. The build now runs `scripts/build-attribution.mjs` first.
4. 1.7 MB of Draco/Basis decoders were shipped but never used (no compressed models). Removed, with the unused glTF loader.
5. The Playwright preview server reused port 4173, so another repo's server could be tested by mistake. Moved to port 4175 with no server reuse.

The agent-based design reviews in `reviews/` led to ten further revisions, R-01 – R-10, logged with their evidence in [`DECISIONS.md`](../../DECISIONS.md) ("Revision log (from Agent review)"): GPU terrain draw fix, crater-ring NaN, panel over cinematics, Module 4 dead end + redo, POI NaN jumps, screen-size lettered pins, 80 m scale ring, text-mode completion state, timed cinematic captions + honest settings, and the honesty/accuracy pass (distance driven, Genesis Rock wording, Dune card, LRV first use, fictional/approximate labels in-app, AS15-89-12100 caption, Front slope figure, EVA 2 order). The headed performance numbers above predate R-01 and will be re-run by the orchestrator.
